# APPSC Economy — Reference Data-Sheets

Compact, flashcard-style **data-sheets** of the numbers that recur across Prelims and Mains — **India figures with Andhra Pradesh alongside**, each with its **source and year** so you quote the right survey. These are lookup sheets to cite *from*; the analysis lives in the note files and [Model Answers](../Model-Answers/README.md).
