## How to use (suggested 7-day cycle for Files 01–05)

1. **Day 1:** File 01 up to "Scope" — make your own definitions card (thinker → phrase) and a POSDCORB mnemonic sheet.
2. **Day 2:** File 01 rest — five paradigms table + NPM/governance chain; the "discipline in India" list (IIPA 1954, Appleby, ARC I & II).
3. **Day 3:** File 02 fully — draw the saptanga wheel and the revenue/personnel/espionage boxes from memory.
4. **Day 4:** File 03 — central offices + mansabdari one day-half; provincial ladder + dahsala the other.
5. **Day 5:** File 04 first half (civil service, Collector, police-judiciary).
6. **Day 6:** File 04 second half (land systems, local self-government, balance sheet).
7. **Day 7:** File 05 — master table + MCQs; write 2 Mains answers under time limit.

**Files 06–10 (a further 10-day cycle):** Day 1 — File 06 up to NGO legal framework (make the Act-year table your flashcard sheet); Day 2 — File 06 rest (the "AP the pioneer" section + criticisms); Day 3 — File 07 statutory + regulatory tables; Day 4 — File 07 tribunals & cases (draw the appeal-path map: SEBI→SAT, TRAI→TDSAT, CCI→NCLAT, NGT→SC); Day 5 — File 08 fully; Day 6 — File 09 good governance + e-governance (AP timeline: CARD→e-Seva→MeeSeva→RTGS→secretariats) + Citizen's Charter/Sevottam; Day 7 — File 09 RTI clause table + Public Services Acts + social audit/SSAAT; Day 8 — File 10 Secs. 1–4 (public service, philosophy, UHV right-understanding vocabulary, codes); Day 9 — File 10 Secs. 5–8 (leadership, work culture, organisational ethics, IR ethics); Day 10 — File 10 Secs. 9–11 (corruption arsenal + Lokpal/Lokayukta clause-facts), then write one Mains answer from each file's practice section.

## Exam-craft notes

- **Prelims/Screening:** APPSC repeatedly asks *thinker–book/definition*, *office–function* (samaharta, mir bakhshi, faujdar), *reform–year–viceroy* matches. Every such pair in these notes is **bolded** — harvest them into flashcards.
- **Mains:** answers score when they (a) open with a crisp definition or periodised thesis line, (b) give 2–3 *specific* institutions or provisions as evidence (an office, a statute, a commission), (c) close with continuity into present-day administration — ideally an **AP tie-in** (Munro and the Ceded Districts, Madras Service Commission 1929 → APPSC, Spandana grievance redressal, village secretariats).
- **Spellings:** exam-standard anglicised forms are used (Kautilya, mansabdari, Ripon) — no diacritics.
- **Disputed "facts":** where scholarship differs (date/authorship of the Arthashastra, exact year mansabdari began), the notes flag it — write "tradition holds…" / "generally dated…" in Mains.
