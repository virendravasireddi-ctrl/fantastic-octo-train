# APPSC Group-I Mains — Study Notes

A structured, source-first revision set for the **Andhra Pradesh Public Service Commission (APPSC) Group-I Mains** (also useful for Group-II and other state PSCs). Notes are written to be *answered from* — every set closes with tables, **bolded match-pairs** for prelims flashcards, MCQs with keys, and Mains answer-skeletons, with **Andhra Pradesh tie-ins** throughout.

This repository consolidates the syllabus notes that were developed on separate feature branches — one subject/paper at a time — into a **single set, organised by paper**. Each paper has its own note-series folder. All **181 note files** now live on one branch: the earlier branches largely repeated each other under different file numbers, so each topic is kept **once**, under one continuous numbering per series.

## How it fits together

The note-series are **separate papers but cross-referenced** where the syllabi meet: Kautilya's revenue state, Mughal land revenue and the British settlements appear in both the History series (Paper-II) and Public Administration (Paper-III), and their fiscal machinery is the ancestor of the Economy series' resource-mobilization system (Paper-IV). Biodiversity, disaster management and sustainable development are treated from the *geography* angle in Paper-II (files 49–58) and from the *science/policy* angle in the Paper-V Science-&-Technology and Environment series — cross-read them.
